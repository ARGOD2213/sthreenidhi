A. OVERDUE LOANS  (the dashboard cannot show them today)
---------------------------------------------------------
Today the dashboard only knows: amount given, amount repaid, loans open/closed.
It has no "overdue" figure. Please tell us:

 1. Does SNBSAP store a REPAYMENT SCHEDULE (EMI / instalment list) for each
    member loan?  If yes: table name, and the columns for
      - loan account number (SHG_MEMBER_LOAN_ACCNO)
      - instalment due date
      - instalment amount due
      - amount paid against that instalment
 2. If there is no schedule table: is there a column on the loan itself for
      - number of instalments / tenure in months
      - EMI amount
      - first instalment date
    (we can compute "due so far" from these).
 3. Is there already a column or view that holds OVERDUE / ARREARS / DEMAND /
    OUTSTANDING PRINCIPAL per loan?  (Some systems call it DEMAND, COLLECTION
    or DCB = Demand, Collection, Balance.)  Table name, column names, and how
    often it is refreshed.
 4. What is the official rule for "overdue" - overdue from the 1st day after the
    due date, or after 30 days?  Is there a rule for NPA (for example 90 days)?
 5. Interest: is interest charged on these loans (the page says "incl.
    interest")?  Where is the outstanding INTEREST kept?
 6. Are there loan statuses other than OPEN and CLOSED (for example WRITTEN-OFF,
    RESCHEDULED, FORECLOSED)?  List all values of LOAN_STATUS.
 7. Please give us a sample: ONE loan with its schedule rows and its repayments,
    so we can check that "due minus paid" gives the right overdue.
